# Психологическое тестирование — сайт для соцпроекта (тема 19)

Статический сайт для GitHub Pages: 5 своих тестов (8–10 утверждений,
оценка от 1 до 5), страница статистики со средними баллами и графиком,
страница контактов.

## Структура

```
index.html            — список тестов (карточки)
test.html              — прохождение теста по ?id=...
results.html           — статистика: средний балл по каждому тесту
contacts.html          — контакты разработчика
data/tests.json        — все тесты и вопросы: id, название, вопросы
css/style.css          — вся стилизация
js/config.js           — один адрес Apps Script для отправки и чтения статистики
js/main.js             — загрузка tests.json + рендер карточек на главной
js/test.js             — логика прохождения теста, подсчёт среднего, отправка результата
js/local-stats.js      — локальная статистика в этом браузере (запасной вариант)
js/results.js          — логика страницы статистики (график Chart.js)
apps-script/Code.gs    — принимает результаты (doPost) и отдаёт статистику (doGet)
```

## Как это работает без бэкенда

GitHub Pages отдаёт только статичные файлы, поэтому весь тест проходится
и считается прямо в браузере (`js/test.js`): пользователь отвечает на
вопросы от 1 до 5, скрипт считает среднее по всем ответам и сразу
показывает результат.

Чтобы результат попал в **общую** статистику (а не остался только у
одного пользователя), нужен Apps Script — see шаг 3 ниже. Пока он не
подключён, сайт полностью рабочий и без него:

- каждый тест считается и показывает результат в браузере;
- страница статистики покажет данные по тестам, пройденным в этом же
  браузере (через localStorage), а если их ещё нет — демонстрационные
  числа, просто чтобы график не был пустым.

## Шаг 1. Проверить/отредактировать вопросы

Все 5 тестов и их вопросы — в `data/tests.json`. Можно менять формулировки,
добавлять или убирать вопросы (8–10 на тест — оптимально для страницы),
менять `duration`, `category`, `description`. Поле `id` менять не стоит,
если уже есть накопленная статистика по этому тесту.

## Шаг 2. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда все файлы этого проекта
   (сохраняя структуру папок `css/`, `js/`, `data/`, `apps-script/`).
2. **Settings → Pages** → в Source выберите ветку `main`, папку `/root`.
3. Через 1–2 минуты сайт появится по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Шаг 3 (важно для реальной статистики). Подключить Apps Script

1. Создайте новую Google Таблицу.
2. В ней: **Расширения → Apps Script**, вставьте туда код из
   `apps-script/Code.gs` (полностью заменив содержимое).
3. **Deploy → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. Скопируйте полученный URL веб-приложения.
5. Откройте `js/config.js` и вставьте этот URL в переменную
   `APPS_SCRIPT_URL`.

После этого каждое прохождение теста будет добавлять строку в таблицу
(лист "Responses" создастся автоматически), а страница `results.html`
будет показывать реальный средний балл и число прохождений по всем
посетителям сайта.

## Шаг 4. Контакты

Откройте `contacts.html` и замените имя, email, Telegram и GitHub на свои.

## Важное примечание

Результаты тестов — это самооценочные показатели для учебного/социального
проекта, а не медицинская или психологическая диагностика. На странице
результата теста уже есть короткая пометка об этом; менять её смысл не
стоит.

## Локальный просмотр

Так как страницы подгружают `data/tests.json` через `fetch`, при простом
открытии `index.html` двойным кликом браузер может заблокировать загрузку
(ограничение `file://`). Проще всего запустить локальный сервер:

```
npx serve .
```

или

```
python3 -m http.server
```

и открыть `http://localhost:8000`.
